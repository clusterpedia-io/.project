# Security Policy

## Reporting Security Issues

The Clusterpedia maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/clusterpedia-io/clusterpedia/security/advisories/new) form.

For more details, see the [Clusterpedia security policy](https://github.com/clusterpedia-io/clusterpedia/blob/main/SECURITY.md).
